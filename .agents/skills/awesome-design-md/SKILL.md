# Awesome DESIGN.md Skill

This skill provides ready-to-use DESIGN.md design system specifications for AI-driven frontend development.

## How to use
1. Reference any design system in `design-md/<brand>/DESIGN.md`.
2. Apply its color palette, typography hierarchy, border radiuses, and tactile micro-interactions to components.
3. Keep mobile ergonomics focused on thumb zones, high contrast legibility, and clean safe-area insets.
